🔑 Configuration Google Drive
1Va sur console.cloud.google.com
Connecte-toi avec ton compte Google habituel.
2Crée un projet : clique sur le menu déroulant en haut ("Sélectionner un projet") → Nouveau projet → nomme-le muscu-tracker → Créer.
3Active l'API Drive : menu hamburger ☰ → API et services → Bibliothèque → recherche Google Drive API → clique dessus → Activer.
4Crée un identifiant OAuth : API et services → Identifiants → + Créer des identifiants → ID client OAuth.
• Type d'application : Application Web
• Nom : Muscu Tracker
• Origines JS autorisées : clique + Ajouter une URI → tape null (pour les fichiers locaux)
→ Créer
5Configure l'écran de consentement (si demandé) : API et services → Écran de consentement OAuth → Type : Externe → remplis juste le nom de l'app (Muscu Tracker) et ton e-mail → Enregistrer. Puis dans Utilisateurs tests, ajoute ton adresse Gmail.
6Copie ton Client ID : retourne dans Identifiants, clique sur ton client OAuth → copie le champ ID client (se termine par .apps.googleusercontent.com).
